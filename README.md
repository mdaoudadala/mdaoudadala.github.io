## 🎨 Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
  --primary-color: #6366f1;
  --secondary-color: #8b5cf6;
  /* ... */
}
```

### Fonts
Change fonts in the HTML head or CSS variables:
```css
:root {
  --font-primary: 'Inter', sans-serif;
  --font-heading: 'Space Grotesk', sans-serif;
}
```
